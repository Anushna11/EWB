RAG & EdTech Academic Project

EduMentor 2.0 – RAG-Based Personalized Learning Assistant

An intelligent educational assistant powered by Retrieval-Augmented Generation (RAG) that delivers contextual, curriculum-aligned study support. By indexing course materials and syllabus documents into a vector database, EduMentor provides students with verified explanations, real-time query answering, and personalized study pacing while minimizing AI hallucinations.

Key Contributions:

  • Contextual retrieval of syllabus-specific lecture content.
  • Adaptive explanations tailored to student learning pace.
  • Interactive Q&A interface for real-time doubt resolution.
